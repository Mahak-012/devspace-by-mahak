## ✨ Features

- ⚡ **Cinematic Hero** — Mouse-tracking glow, animated grid, twinkling stars, parallax depth
- 🖥️ **Terminal Widget** — Typewriter animation with blinking cursor
- 🔵 **Tech Badge Ring** — Rotating "Open to Work" SVG ring with floating skill badges
- 📊 **Animated Stats Bar** — Project count, uptime, passion — all displayed with style
- 🎯 **Smooth Navigation** — Hash-based section scrolling with active link indicator
- 💌 **Contact Section** — Fully functional inquiry form
- 🌙 **Dark Aesthetic** — Deep navy background, cyan accents, subtle glow effects
- 🎞️ **Page Transitions** — AnimatePresence route animations throughout
- 📱 **Fully Responsive** — Mobile-first, hamburger drawer, works on all screen sizes
- 🚀 **Production Ready** — Optimized build, deployed on Vercel

## 🚀 Getting Started

### Prerequisites
- Node.js v18+
- npm

### Installation

```bash
# Clone the repo
git clone https://github.com/Mahak-012/devspace-by-mahak.git

# Navigate into the project
cd devspace-by-mahak

# Install dependencies
npm install

# Start development server
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.

### Build for Production

```bash
npm run build
npm run preview
```

## 🎨 Design System

### Colors

| Name | Hex | Usage |
|------|-----|-------|
| Background | `#050A0F` | Page background |
| Cyan Accent | `#00D4FF` | Primary accent, highlights |
| White | `#FFFFFF` | Headings |
| Muted | `rgba(255,255,255,0.4)` | Body text |
| Border | `rgba(0,212,255,0.15)` | Card borders |

### Typography

| Font | Weight | Usage |
|------|--------|-------|
| Barlow Condensed | 800 | Hero headlines |
| DM Sans | 300–800 | Body, UI elements |
| DM Mono | 400–500 | Terminal, code snippets |

### Key Animations

| Effect | Description |
|--------|-------------|
| Mouse glow | Cyan radial gradient follows cursor |
| Grid overlay | Subtle cyan grid on dark background |
| Terminal typewriter | Character-by-character text reveal |
| Badge ring | SVG circular text rotating continuously |
| Scroll reveal | whileInView fade+slide per section |
| Page transitions | AnimatePresence fade between routes |
